# 笔记格式与关系图谱约定

正文以中文为主，专业术语保留 English。开头先写结论、事实状态与验证结果，
再呈现背景、理由、失败尝试和证据。空缺写“尚未确定”或“未运行”，不填造原因。

保持交接文档的 Decision / Pitfall / Milestone 分类。每类使用简短标题和二级标题；
失败尝试逐项列出，避免把长日志塞进表格。证据只保留必要摘要、路径、时间与 hash。
事实状态、因果状态和测试状态各自独立。

文件名使用稳定 entry_id 和创建时的中文标题，后续修改标题不改文件名。
当前中文标题写在 H1 和 YAML aliases 中。原生图谱显示文件名，aliases 用于搜索。
YAML 属性使用 JSON 兼容值，避免冒号、引号及中文引起解析歧义。

所有生成的双链使用 Vault 相对完整路径。多个项目的记录身份可以相同，链接目标仍唯一。
项目主页文件名也带项目名称，图谱中的同类节点可以区分。显示文字使用中文标题。
项目主页链接记录，记录链接主页；可复用经验链接全部来源记录，来源记录也链接经验。

图谱按 Decisions、Pitfalls、Milestones、Reusable-Knowledge 分组着色。
默认隐藏标签节点、附件和未解析目标，排除 Templates，避免低价值节点掩盖关系。
从项目主页打开 Local graph，深度设为 2，可查看项目记录及共享经验。
完整路径双链用于关系图谱；Mermaid 图只作正文说明，不能替代 Obsidian 链接。

生成规则参考 ADR 的背景、决定与后果结构，结合本项目要求增加证据与独立状态标记。
不依赖 Dataview、AI 插件或 MCP。阅读宽度与标题间距由一个本地 CSS snippet 调整。
